# VolSurf

Implied volatility surface visualizer for tracking skew across expiries and strikes, built in Rust on top of Interactive Brokers' TWS API.

## Why

Checking skew one expiry and one strike at a time in the option chain is slow. The goal is a single view where skew changes stand out.
